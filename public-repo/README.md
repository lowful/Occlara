# Occlara

Occlara is a post-match coach for Valorant. It watches your screen while you play, shows nothing during the match, and when the match ends it opens a graded review: a score out of 100, your repeated mistakes with a fix for each, what went well, and drills to practise.

**Download:** [Occlara-Setup.exe](https://github.com/lowful/Occlara/releases/download/Release/Occlara-Setup.exe) or [occlara.app](https://occlara.app)

## What this repository is

This is the full source of the Occlara app, the program that runs on your PC. It is published so anyone can check what the app does before installing it. [TRUST.md](TRUST.md) lists each promise the app makes and the file that shows it.

The coaching itself (reading the match, writing the review, answering questions) runs on Occlara's server, which is not part of this repository.

Each release of the app publishes its source here. The code is visible for inspection only: see [LICENSE](LICENSE).
